# BlueRetro Companion premade profiles.
#
# Each profile is a [Name] line followed by one mapping per line:
#
#   SOURCE,DEST[,max[,threshold[,deadzone[,turbo]]]]
#
# SOURCE is the button on the Bluetooth controller, DEST is what the GameCube
# sees. Names are the ones the Live input viewer prints, so whatever is on
# screen there can be typed straight in here. max, threshold, deadzone and
# turbo default to 100, 50, 0 and 0.
#
# A profile replaces the whole mapping for that controller, so list everything
# it should do. The reset, pairing and power off combos are added for you and
# do not need listing.
#
# Face buttons are RB_DOWN, RB_RIGHT, RB_LEFT and RB_UP, meaning the bottom,
# right, left and top of the diamond as your thumb sees it.
